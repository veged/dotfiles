# Установка AI-компонента

Прочитай `../../commands/install.toml` полностью и исполни значение `prompt` как
шаблон команды.

Считай `{{args}}` текстом, переданным после `/dotfiles:install`. Если аргументов
нет, следуй правилу пустого входа из шаблона.
