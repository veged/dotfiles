# CLI

Используй `ugrep` вместо `grep`, `fd` вместо `find`, `sd` вместо `sed`, `eza` вместо `ls`, `xh` вместо `curl`, `tldr` вместо `man`. Для JSON используй `jq`, для YAML/TOML/XML/CSV — `yq`, для GitHub — `gh` вместо Fetch/WebFetch. У `xh` нет `--retry`, коды 4 и 5 означают ошибки 4xx и 5xx.

- Минимизируй пайпы средствами `jq`/`ugrep`/`fd`. Для обработки файлов предпочитай `fd -x` вместо `xargs`. Учитывай пробелы в путях, для `xargs` используй `fd -0 | xargs -0`.
- Перед деструктивной командой просмотри изменения (`sd -p`) или список целей без удаления.
- Если TTY нет и ввод не нужен, закрывай stdin через `< /dev/null`. Отключай пейджер (`git --no-pager`). Не запускай `read`, `fzf` и другие интерактивные команды без TTY или неинтерактивного режима.
- Сетевым командам задавай таймаут. `yield_time_ms` ограничивает ожидание, а не длительность процесса.
- Выводи полный результат `exec_command` через `text(r)`, сохраняя `session_id` и `exit_code`. При `session_id` продолжай через `write_stdin`, при `cell_id` внешнего `functions.exec` — через `wait`. Без `exit_code` успех не подтверждён.

Перед финалом дождись своих поисков либо останови свои цепочки процессов целиком и проверь завершение. Координатор проверяет это при приёмке сабагента. Фоновая работа требует явного владельца.
