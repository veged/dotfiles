# Поиск

Для локального поиска используй инструменты текущей сессии; в CLI предпочитай `ug` и `fd`.

`~/arcadia` — виртуальный Arc mount: не обходи его корень рекурсивно. Для широкого поиска по Arcadia используй `community-intrasearch`; локальный поиск допустим только в известном ограниченном поддереве.
