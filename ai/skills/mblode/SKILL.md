# Процедуры mblode

Выбери процедуру по результату запроса, сохраняя явно выбранный пользователем подход. `product-design` определяет поведение, `ui-design` создаёт интерфейс, `ui-audit` проверяет готовый. `tidy` меняет код, поэтому не выбирай его для запроса только на ревью. Для явно запрошенного ревью через mblode доступен также `pr-reviewer`, он только читает изменения.

До выполнения выбранной процедуры прочитай исходный `SKILL.md`: `~/.codex/plugins/dotfiles-local/mblode/skills/<имя>/SKILL.md`. Явное имя поднавыка имеет приоритет над подбором по описанию. Если нужного файла нет, сообщи об этом, не заменяя его похожим.

| Требуемый результат | Имя |
|---|---|
| Создать или проверить план реализации | `planning` |
| Архитектура TypeScript, модули и устройство кодовой базы | `codebase-architecture` |
| Архитектура SaaS с несколькими арендаторами | `multi-tenant-architecture` |
| Поведение интерфейса, сценарии, состояния и последствия действий | `product-design` |
| Создание, оформление и адаптация интерфейса | `ui-design` |
| Дефекты реализованного React/Next.js-интерфейса | `ui-audit` |
| Архитектура, управление и доверие в агентном приложении | `ax-audit` |
| Проектирование и реализация движения в интерфейсе | `ui-animation` |
| Подробная проверка типографики | `typography-audit` |
| Тексты продукта и интерфейса | `copywriting` |
| Проверка отображения приложения со снимками и журналом браузера | `browser-evidence` |
| Контракты, ошибки и удобство использования CLI, SDK или библиотеки | `dx-audit` |
| SEO и технические настройки Next.js App Router | `optimise-seo` |
| Техническая документация и описание API | `docs-writing` |
| README для пользователей проекта | `readme-creator` |
| Аудит и улучшение AGENTS.md или CLAUDE.md | `agents-md` |
| Создание и улучшение SKILL.md | `agent-skills-creator` |
| Презентация и её повествовательная структура | `presentation-creator` |
| Новый TypeScript CLI и npm-пакет | `scaffold-cli` |
| Новый проект Next.js | `scaffold-nextjs` |
| Создание PR или редактирование его заголовка и описания | `pr-creator` |
| Наблюдение за PR, разбор CI и замечаний | `pr-babysitter` |
| Выпуск существующего npm-пакета через changesets | `autoship` |
| Проверка текущих изменений с применением исправлений | `tidy` |

Загружай только выбранную инструкцию и необходимые ей ресурсы. Относительные ссылки разрешай от исходного каталога навыка. Не копируй его текст сюда и не загружай весь набор. Выбор процедуры не разрешает публикацию, отправку сообщений, Git-интеграцию или расширение дерева агентов: действуют разрешения пользователя и общий бюджет.
