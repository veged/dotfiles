# Транскрибирование видео

## Принцип

Строить чистый транскрипт только после сопоставления независимых свидетельств:

`Whisper large-v3 + FluidAudio/Parakeet TDT v3 + все доступные субтитры + опциональные материалы`.

Whisper и Parakeet обязательны для всей записи. Субтитры обязательны, когда источник их предоставляет. Материалы помогают писать термины, но не доказывают, что фраза была произнесена.

## Контракт источников

| Источник | Роль | Условие готовности |
| --- | --- | --- |
| Исходное аудио | Главная проверка спорных мест | Доступна полная запись |
| Whisper | Основной локальный ASR | Распознана вся запись моделью `large-v3` или более качественной |
| FluidAudio | Независимый дополнительный ASR | Вся запись распознана Parakeet TDT v3; получен JSON с `wordTimings` |
| Субтитры | Третье текстовое свидетельство и таймкоды | Получены все подходящие ручные и автоматические дорожки |
| Материалы | Имена, термины, формулы, структура | Использованы только как словарь и контекст |

Существующий транскрипт, хорошие субтитры или один ASR не заменяют остальные обязательные источники.

## Рабочий процесс

### 1. Проверить вход и разрешения

1. Определить URL или локальный медиафайл, длительность, язык и путь результата.
2. Проверить `yt-dlp`, `ffmpeg`, локальный Whisper, `swift` и FluidAudio.
3. Создать временный каталог. Хранить в нём аудио, субтитры, ASR JSON и словарь.
4. До загрузки отсутствующей крупной модели сообщить её точный размер либо честную оценку и запросить разрешение. Облачный ASR использовать только по явному разрешению.
5. Если `transcript.md` существует, писать `<slug-видео>-transcript.md`, если пользователь не разрешил перезапись.

### 2. Получить медиа и субтитры

Для URL сначала изучить источник:

```bash
yt-dlp --list-subs --skip-download URL
yt-dlp --write-subs --write-auto-subs --sub-langs 'all,-live_chat' \
  --sub-format 'json3/vtt/srt/best' --skip-download -o "$TMP/source" URL
yt-dlp -x --audio-format wav -o "$TMP/audio.%(ext)s" URL
```

Для локального файла извлечь несжатый mono PCM 16 kHz через `ffmpeg`, сохранив оригинал. Нормализовать субтитры без служебных событий и дублей, сохранив интервалы.

Если субтитров нет, продолжить с двумя ASR и сообщить об отсутствии третьего источника при сдаче результата.

### 3. Построить временный словарь

Прочитать доступные Markdown, документы, PDF, слайды, страницы и словари. Выписать в `$TMP/terms.txt` только имена, продукты, технологии, аббревиатуры, формулы и заголовки. Не переносить из материалов тезисы или предложения в транскрипт.

### 4. Выполнить два полных распознавания

**Основное:** распознать всю запись лучшим доступным локальным Whisper с мультиязычной `large-v3`, таймкодами и confidence. Сохранять исходный язык; русский задавать как hint при сильном русском контексте, не запрещая иноязычные фрагменты.

**Дополнительное:** на Apple Silicon использовать закреплённый FluidAudio `v0.15.5`:

```bash
swift run -c release fluidaudiocli transcribe "$TMP/audio.wav" \
  --language ru \
  --word-timestamps \
  --output-json "$TMP/parakeet.json" \
  --custom-vocab "$TMP/terms.txt"
```

Выбирать фактический код языка вместо `ru`. Проверить `wordTimings`, длительность и покрытие. Не использовать внутренний HTTP API FluidVoice.

Если FluidAudio не запускается, использовать `sherpa-onnx` с Parakeet TDT v3. Если второго независимого ASR всё равно нет, остановиться и запросить решение пользователя.

Не передавать текст Whisper в Parakeet и наоборот: распознавания должны оставаться независимыми.

### 5. Сопоставить свидетельства

1. Привести таймкоды к секундам от начала исходника.
2. Сопоставить короткие фрагменты Whisper, Parakeet и субтитров по времени и близости текста.
3. Выделить пропуски, несовпадения и низкую уверенность.
4. Для каждого существенного расхождения переслушать узкий фрагмент с контекстом до и после.
5. Только после прослушивания использовать материалы для выбора написания среди фонетически правдоподобных вариантов.
6. Если сомнение осталось, написать `[неразборчиво, 12:34]` или `[вероятно: SourceCraft]`.

Слайд подтверждает орфографию термина, но не сам факт его произнесения в конкретной реплике.
Если спорный фрагмент фактически не переслушан или аудио недоступно, не объявлять вариант уверенным даже при совпадении всех текстовых источников; использовать `[вероятно: …]`.

### 6. Отредактировать без сокращения смысла

- Сохранить порядок, все мысли, примеры, шутки, эмоциональные акценты и вопросы.
- Удалить слова-паразиты, бессмысленные повторы и ложные старты.
- Исправить пунктуацию, очевидные оговорки и единообразие терминов.
- Не превращать речь в конспект, пересказ или литературную статью.
- Размечать участников нейтрально: `Спикер:`, `Участник:`. Не придумывать имена и не запускать полную диаризацию без необходимости.
- Начинать смысловые разделы и самостоятельные реплики с таймкода. Для веб-видео делать его ссылкой на исходный момент; для локального файла использовать `[ЧЧ:ММ:СС]`.
- Выдать только чистовой Markdown, без резюме методики и сырых ASR-файлов.

## Проверка перед завершением

- Покрыта вся запись от первой до последней реплики, включая вопросы.
- Проверены интервалы, присутствующие только в одном источнике.
- Переслушаны все существенные расхождения и участки низкой уверенности.
- Дополнительные материалы не породили отсутствующую речь.
- Термины единообразны, говорящие не потеряны, ссылки с таймкодами корректны.
- Markdown перечитан целиком и проверен доступным линтером.

После успеха удалить временные файлы. При ошибке сохранить временный каталог и сообщить путь.

## Типичные обходы

| Обход | Правильное действие |
| --- | --- |
| «Автосубтитры уже хорошие» | Всё равно выполнить Whisper и Parakeet |
| «Одного Whisper достаточно» | Выполнить независимый Parakeet для всей записи |
| «Слайд однозначно доказывает фразу» | Сначала переслушать соответствующий аудиофрагмент |
| «Все тексты совпали, можно не слушать» | Без фактического прослушивания оставить `[вероятно: …]` |
| «Транскрипт уже существует» | Проверить его полным процессом или создать новый файл |
| «Субтитров нет» | Продолжить с двумя ASR и отметить деградацию при сдаче |
| «Второй ASR установить трудно» | Запросить разрешение или остановиться; не снижать процесс молча |
