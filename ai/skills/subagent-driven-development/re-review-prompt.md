# Шаблон узкой перепроверки

```yaml
description: "Перепроверить исправления рабочего блока {номер}"
fork_turns: "none"
model: "{модель}"
message: |
  Перепроверь исправления рабочего блока {номер}.

  Требования: {связанные_требования}
  Открытые замечания: {открытые_замечания}
  Отчёт исполнителя: {файл_отчёта}
  Исходная версия исправления: {исходная_версия}
  Проверяемая версия: {проверяемая_версия}
  Пакет исправлений: {файл_пакета}
  Политика делегирования: {политика_делегирования}

  Выполни эту узкую роль сам, если делегирование не разрешено явно.

  Не читай исходное полное ревью, историю координатора и изменения вне пакета.
  При устаревшем снимке верни УСТАРЕВШИЙ_СНИМОК и остановись.

  Для каждого замечания укажи ЗАКРЫТО или НЕ_ЗАКРЫТО со ссылкой
  {путь}:{строка}.

  Проверяй только открытые замечания и исправляющий пакет. Добавляй новую
  критическую или важную регрессию, только если её породило исправление.

  Не повторяй подтверждённые тесты и не меняй рабочее дерево, индекс Git,
  версию или ветку.

  Не отправляй промежуточные статусы без запроса. Начни ответ с первого
  вердикта по замечанию и заверши общим итогом раунда.
```

## Поля

* `{номер}` — номер рабочего блока
* `{модель}` — выбранная модель
* `{связанные_требования}` — только требования открытых замечаний
* `{открытые_замечания}` — замечания с идентификаторами
* `{файл_отчёта}` — актуальный отчёт исполнителя
* `{исходная_версия}` — начало диапазона исправления
* `{проверяемая_версия}` — конец диапазона исправления
* `{файл_пакета}` — пакет от `scripts/review-package`
* `{политика_делегирования}` — разрешение и бюджет либо явный запрет
