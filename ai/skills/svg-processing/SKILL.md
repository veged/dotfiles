# Обработка SVG

* Inkscape запускай через штатный запрос выхода из песочницы, иначе блокируется регистрация графического приложения.
* Для прямого преобразования SVG в PNG, PDF, PS или EPS используй `rsvg-convert`, если не нужны возможности, специфичные для Inkscape. Для PDF, PS и EPS обязательно укажи `--format pdf`, `--format ps` или `--format eps`: формат не определяется по расширению выходного файла. Не запускай для этого `magick input.svg output.png`.
* Если после рендеринга нужны растровые операции ImageMagick, сначала создай временный PNG через `rsvg-convert`, затем передай PNG в `magick`.
* Для сложного SVG с критичной точностью отображения явно выбери подходящий движок и проверь результат визуально; не подменяй его другим движком молча.

Сохраняй исходный SVG. Для промежуточного растра используй отдельный файл. Не перезаписывай единственный ценный результат и не удаляй артефакты без действующего разрешения пользователя.
