# Классы кандидатов

Используй только строки, соответствующие найденным объектам.

| Класс | Проверка | Безопасное действие |
|---|---|---|
| Пользовательские данные | Источник, резервная копия, синхронизация | Не трактовать как кэш |
| Хранилище приложения | Синхронизация, активный процесс, встроенное управление | Очищать через приложение; закрыть его перед ручным удалением |
| Сборки и пакеты | Цена повторной сборки/загрузки | Штатные команды наподобие `cargo clean`, `go clean -cache`, `npm cache`; для Homebrew сначала `brew cleanup -n` |
| Версионный кэш | Ссылки, внутренняя база, lock-файлы, требования проектов, последнее использование | Сохранить текущие и недавние версии; удалить старые неподключённые |
| Кэшированный репозиторий | `git status`, локальные ветки, незапушенные коммиты | Удалять только чистый воспроизводимый клон |
| Резервная или мигрированная копия | Возраст, содержимое текущего источника, процесс-владелец | Удалять после подтверждения, что текущий источник полон и используется |
| Контейнерная машина | Активный профиль; различие загрузочного кэша, образов, томов и диска VM | Чистить штатно; том требует отдельного разрешения; отличать старое хранилище от текущего |
| Динамический VM-образ | Виртуальный размер против выделенных блоков; состояние VM | Удаление внутри гостя не возвращает место хосту: TRIM → полное выключение → резервная копия → штатный reclaim/compact |

Для дорогого восстановления ограничивай очистку возрастом и неподключённостью, а не максимальным потенциальным выигрышем.
