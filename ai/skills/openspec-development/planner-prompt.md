# Планировщик OpenSpec

Изменение: `{CHANGE_NAME}`

Состояние: `{STATE_FILE}`

Отчёт: `{REPORT_FILE}`

Прочитай полные JSON-ответы доступного CLI OpenSpec. Обновляй только активные
артефакты этого изменения. При исправлении артефакта вычисли затронутые
выполненные пункты и сними `done` только с них. Проверь изменение средствами
CLI и запиши результат по путям `{REPORT_FILE}` и `{STATE_FILE}`.

Верни одну строку: `READY`, `BLOCKED` или `UPDATED`; пояснение и пути — в
отчёте. Ответ — не более 15 строк.
