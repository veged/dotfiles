# Переносы текста в Markdown

`remark-unwrap-text.mjs` заменяет LF, CRLF и CR пробелом только в узлах `text` и сообщает о каждом изменённом узле. Обрабатывает также текст внутри списков, цитат, выделения и ссылок. Явные разрывы строк, встроенный код, блоки кода и HTML остаются в своих узлах. Настройки сериализации remark сохраняются.

Плагин не имеет зависимостей. Он использует идею преобразования из [remark-unwrap-texts](https://github.com/phuctm97/remark-unwrap-texts). Диагностика сообщает только о разворачивании текста, тогда как [unified-consistency](https://github.com/remcohaszing/unified-consistency) сравнивает весь результат сериализации с исходником.

## Использование

Плагин подключён в `tools/remark/remarkrc.json`. Из корня dotfiles:

```sh
./scripts/remark --frail --quiet документ.md
./scripts/remark --output документ.md
npm --prefix tools/remark test
```

`--frail` возвращает ненулевой код при нарушениях и не меняет файл. `--output` сохраняет исправленный Markdown по текущим настройкам remark. Предупреждения относятся к исходному тексту, после исправления повторная проверка проходит.

## Другие проекты

Скопируйте `remark-unwrap-text.mjs` и добавьте путь к нему в `plugins` своего конфига remark. При программном вызове импортируйте плагин и подключите через `.use(remarkUnwrapText)`. Установка общего запускателя dotfiles не изменяет локальные конфигурации других проектов.
